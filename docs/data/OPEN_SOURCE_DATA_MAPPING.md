# DATA-4.1 公开数据映射与真实性边界

状态：已实现。当前业务页面主数据链路为 `公开源快照 → PostgreSQL raw → staging → core → 已发布语义层 → 后端 API → 前端`。旧固定种子模拟数据仅保留为回归 fixture，模拟场站和设备在 DATA 运行时标记为 `fixture`，不会进入活动场站权限集合。

## 活动数据源

| 场景 | 来源 | 许可证 | 快照 | 时间范围 | 运行标识 |
|---|---|---|---:|---|---|
| charging_ops | ACN-Data，经 ORNL OpenEnergyDataPortal 分发 | CC BY 4.0 | 26/26 条发现副本记录 | 2020-05-09 至 2020-06-09 | `DATA41-ACN-ORNL-26-V1` |
| sales_ops | UCI Online Retail | CC BY 4.0 | 27,095/541,909 条确定性样本 | 2010-12-01 至 2011-12-09 | `DATA41-UCI-ONLINE-RETAIL-352-V1` |

UCI 快照按原工作簿顺序保留每第 20 个数据行，并保留 `source_row_number`。它是全周期样本，不是全量副本。源 ZIP、提交快照和每条 raw 记录均有 SHA-256 校验。

## 真实性与派生规则

- ACN 的连接、断开、完成充电、交付电量、站点、用户输入均为源字段；金额不是源字段。
- ACN 支付必需记录按 Caltech 当期公开费率 `USD 0.12/kWh` 派生服务费；电能成本按 EIA 2020 美国商业平均电价 `USD 0.1059/kWh` 派生。两者均在映射 JSON 中标成派生规则，不代表场站真实结算价。
- ACN 源未提供设备状态，因此不生成设备状态事件；在线率、故障率会显示数据不足，禁止虚构补齐。
- UCI 数量、单价、发票、商品、客户编号和国家为源字段；成本缺失，使用明确的 70% 场景成本假设以维持毛利口径演示，不能当作企业真实成本。
- UCI 缺失客户编号以发票范围的散列匿名键承接；不恢复身份，不引入个人信息。

## 质量门禁

新链路执行 28 项检查，覆盖唯一性、必填、类型、日期范围、金额、电量、引用完整性、重复、顺序、异常值观察、文件哈希、行数、版本及转换对账。任一失败时摄取运行标记为 `FAILED`，初始化失败关闭。旧模拟基线的 DQ-001 至 DQ-020 测试保持不变并纳入完整回归。

## 许可与候选源决策

- NREL AFDC 保留在候选目录，因验收环境无法稳定解析官方 API 主机，本阶段没有将未验证下载内容写入数据库。
- PJM Data Miner 2 的官方说明包含再分发限制，本阶段不提交 PJM 数据快照，也不将其标成活动数据源。
- Word 方案提到 sales_ops 使用 MySQL；DATA-4.1 的明确实施要求规定所有 UI 数据统一走 PostgreSQL→API→前端，因此本阶段按更高优先级当前指令使用 PostgreSQL，未引入第二业务数据库。

机器可读映射见 `docs/data/open_source_data_mapping.json`，源清单见 `data/open_source/source_manifest.json`，SQLBot 预备目录见 `docs/data/schema_catalog.json`。SQLBot 本阶段仍禁用。
