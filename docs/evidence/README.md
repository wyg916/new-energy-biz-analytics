# Alpha 作品证据

本目录保存由 Playwright 在 Docker Compose 冷环境中生成的页面截图。截图只展示固定种子模拟数据，不代表真实企业部署或真实经营收益。

- `screenshots/01-login.png`：认证入口与模拟数据声明。
- `screenshots/02-dashboard.png`：数据库驱动的经营驾驶舱。
- `screenshots/03-chatbi.png`：可信问数回答、Query Plan 和证据面板。
- `screenshots/04-diagnostics.png`：毛利桥接、场站贡献和因果边界。
- `screenshots/05-report.png`：可审核月报草稿和导出入口。
