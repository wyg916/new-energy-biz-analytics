# KB00｜项目二知识基线包说明

> 包版本：`1.0.0`  
> 生成日期：`2026-08-09`  
> 适配基线：`0a2c776cd6ba47598a17286a793f3c570823cf77`  
> 目标：为 Integration-4.1-Core 的 Governed Hybrid RAG V1 提供首个非空、可发布、可引用的业务知识基线。

## 包含内容

1. 15 项核心指标定义；
2. 数据字典；
3. charging_ops 业务规则；
4. sales_ops 业务规则；
5. 收入与成本计算规则；
6. 公开数据接入说明；
7. 业务分析方法；
8. SQL/权限安全规则；
9. 项目功能使用说明。

## 事实优先级

知识包发生冲突时按以下顺序判断：

1. 当前数据库/发布语义模型/机器可读运行证据；
2. 当前 Integration HEAD 的代码与迁移；
3. DATA-4.1 Schema Catalog / Mapping；
4. 指标与安全合同；
5. 本知识基线的解释性文本。

本包不覆盖运行时事实，不将缺失数据补成经营数值。

## 当前数据边界

- charging_ops：当前活动公开源为 ACN-Data 的 DATA-4.1 受控快照；
- sales_ops：当前活动公开源为 UCI Online Retail 的 DATA-4.1 受控快照；
- 派生经营字段和业务假设必须保留版本化依据；
- 不同场景的金额不做无治理跨场景加总；
- 没有设备状态事实时，不回答设备在线率/故障率的具体值。

## RAG 发布原则

- 文件仅在进入 `APPROVED_SOURCE_PATHS` 后允许摄取；
- 摄取后状态到 READY 不等于已发布；
- 发布必须使用有权限的真实管理员身份；
- 自动治理角色可以做质量检查，但不能冒充人工身份执行发布；
- 发布后检查 `published_chunk_count == indexed_chunk_count`；
- Citation 必须绑定版本和 locator。
