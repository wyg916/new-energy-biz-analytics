# KB07｜业务分析方法与诊断边界

> 知识域：`analysis_method`  
> 场景：`charging_ops`、`sales_ops`  
> 版本：`1.0.0`

## 1. 分析总原则

经营分析遵循：

`定义问题 → 明确时间/范围 → 选择指标 → 校验数据完整性 → 比较/拆解 → 定位对象 → 形成证据 → 给出建议`

所有结论必须：

- 绑定当前授权范围；
- 绑定 DatasetVersion、SemanticModelVersion 和 run_id；
- 区分事实、派生指标和业务假设；
- 不把同期变化直接描述为因果关系。

## 2. 指标查询

适用于：

- “某时间段收入多少？”
- “订单数、电量、毛利率分别是多少？”

要求：

- 指标必须在发布语义层；
- 时间范围明确；
- 缺少必要字段时返回数据不足；
- 数字来自结构化结果，Answer Guard 不允许补造数字。

## 3. 趋势分析

典型：

- 日/周/月趋势；
- 峰值/低谷；
- 连续变化方向。

建议步骤：

1. 按统一时间粒度聚合；
2. 检查数据覆盖；
3. 对比期使用相同粒度；
4. 标记显著变化点；
5. 再进入诊断，不直接从趋势图推因果。

## 4. 环比与同比

### 环比

对于完整自然月，比较上一自然月。

对于一般窗口，当前实现可使用“等长前置窗口”。

### 同比

比较上一年相同时间窗口。

结果至少包含：

- current
- previous
- absolute_change
- change_rate

前值为 0/NULL 时，变化率返回数据不足。

## 5. 收入拆解

当前 charging_ops 对收入变化支持：

### 5.1 电量效应

`volume_effect = (current_volume - previous_volume) × previous_revenue_per_kwh`

### 5.2 度电收入效应

`price_effect = current_volume × (current_revenue_per_kwh - previous_revenue_per_kwh)`

### 5.3 残差

`residual = revenue_change - volume_effect - price_effect`

残差用于保证桥接对账，不应被解释成未经验证的业务原因。

## 6. 毛利拆解

当前毛利变化桥接：

- 收入变化：正向贡献；
- 电费成本变化：反向贡献；
- 可变运营成本变化：反向贡献。

即：

`gross_profit_change ≈ revenue_change - energy_cost_change - variable_operating_cost_change`

所有贡献之和必须与目标变化对账。

## 7. 场站贡献分析

对每个授权场站分别计算：

`contribution = current_metric - previous_metric`

按绝对贡献排序，用于识别主要变化对象。

仅对当前用户授权场站执行，不能利用排名结果泄露无权限场站存在性。

## 8. 异常检测

当前规则型异常使用环比变化率：

`change_rate = (current - previous) / |previous|`

默认阈值：

`0.15`

当前实现中：

- 未达到阈值：`none`
- 达到阈值：`medium`
- 绝对变化达到 `2 × threshold`：`high`

这是业务规则异常，不是统计因果检测。

## 9. 同群对比

场站 Peer 对比使用当前授权场站集合：

- 当前场站值；
- 同群中位数；
- 当前场站百分位；
- 同群有效样本数。

“高于同群中位数”只表示相对位置，不构成原因解释。

## 10. 排名

Ranking 至少需要：

- 指标；
- 实体维度；
- 排序方向；
- limit。

默认 Top/Bottom 结果不能绕过权限过滤。

## 11. 数据 + 知识联合分析

当问题同时需要业务数字和制度/口径解释时：

1. 数据链路通过 Query Plan / SQL Guard 获取结构化结果；
2. RAG 只检索当前场景、当前 ACL、已发布且有效的知识；
3. Answer Guard 校验数字必须来自结构化结果；
4. Citation 绑定 document/version/chunk/page/section/paragraph locator；
5. 没有已发布证据时拒绝知识性断言。

## 12. 诊断因果边界

当前系统允许：

- “同期变化”
- “关联线索”
- “疑似影响因素”
- “贡献变化”

不允许仅凭当前诊断直接说：

- “A 导致 B”
- “故障率上升造成收入下降”
- “某场站一定因为某因素表现变差”

若需要因果结论，必须有独立实验、准实验或因果识别设计。

## 13. 推荐经营分析模板

### 充电运营

1. 收入/电量/订单；
2. 单均电量/度电收入；
3. 环比或同比；
4. 场站贡献；
5. 能源成本/毛利；
6. 数据完整性；
7. 设备状态事实存在时再做可用性诊断。

### 销售经营

1. 净收入/订单/客户；
2. 客单价/销量；
3. 区域/渠道/产品排名；
4. 退款；
5. 毛利；
6. 新客/复购；
7. 对成本假设单独说明。
