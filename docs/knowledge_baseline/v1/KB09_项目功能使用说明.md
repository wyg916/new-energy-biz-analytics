# KB09｜项目功能与提问使用说明

> 知识域：`system_help`  
> 场景：`charging_ops`、`sales_ops`  
> 版本：`1.0.0`  
> 适用基线：Integration-4.1-Core

## 1. 当前平台能力

当前核心能力包括：

- 经营驾驶舱；
- 收入/经营指标分析；
- 15 项 charging_ops 核心指标；
- sales_ops 第二场景；
- Deterministic ChatBI；
- 受治理 Hybrid RAG V1；
- 会话状态与 Memory；
- Memory Lifecycle / 自动遗忘；
- 异常、拆解、同群对比；
- 报告草稿/导出基础；
- 数据接入与发布；
- OIDC/RBAC；
- 审计、版本、迁移、回滚。

SQLBot/Open NL2SQL 的正式启用状态必须以当前运行时门禁为准，不能根据界面入口或代码存在性推断已经 Stable。

## 2. 经营驾驶舱

适合：

- 查看指标摘要；
- 查看趋势；
- 查看场站/区域表现；
- 查看当前业务时间范围；
- 进入诊断或 ChatBI。

页面业务值来自：

`PostgreSQL → Backend API → Frontend`

接口异常时不应显示替代经营值。

## 3. ChatBI

### 推荐问题结构

`时间 + 场景/范围 + 指标 + 分析方式`

例如：

- “2020 年 5 月 9 日到 6 月 9 日 charging_ops 充电量是多少？”
- “按场站比较充电收入。”
- “销售场景按国家/区域看净收入排名。”
- “这个月收入比上个周期变化多少？”
- “毛利下降主要是收入还是成本变化？”

### 系统会澄清的情况

- 指标不明确；
- 时间不明确；
- 场景不明确；
- 同名实体有多个候选；
- 请求超出活动数据范围；
- 请求使用未发布指标/维度；
- 用户请求范围超过权限。

## 4. RAG 知识问答

RAG 适合回答：

- 指标口径；
- 数据字段含义；
- 业务规则；
- 计算公式；
- 数据接入；
- 分析方法；
- SQL安全；
- 功能使用帮助。

检索必须：

- 先做 tenant/workspace/scenario/role/data_scope ACL；
- 只使用已发布且有效的知识版本；
- Citation 绑定 document/version/chunk；
- 提供 page/section/paragraph locator；
- 无合格证据时拒答。

## 5. 数据 + 知识联合问题

例如：

“当前充电量是多少？这个指标口径怎么定义？”

正确处理：

1. 数据部分走结构化查询；
2. 口径部分走 RAG；
3. 数字只来自结构化结果；
4. 知识解释附 Citation；
5. Answer Guard 检查结果一致性。

## 6. Memory

Memory 用于保存受控会话/长期上下文，包括：

- 工作记忆；
- 已确认的语义记忆；
- 成功分析运行摘要；
- 程序/技能版本。

Memory 不得扩大权限，也不能让旧记忆覆盖当前数据库事实。

## 7. 自动遗忘

生命周期系统可执行：

- TTL；
- 有效期；
- 重要性衰减；
- recall signal；
- REDUCED_RANK；
- COLD；
- ARCHIVED；
- REVOKED/DELETED；
- Legal Hold；
- Outbox 重试；
- delete verification；
- delete-no-recall。

用户删除请求和治理任务必须有审计。

## 8. Diagnostics

当前支持：

### 分解

- 充电收入变化拆解；
- 毛利变化拆解。

### 异常

使用规则阈值检测经营变化。

### Peer

场站与授权同群比较：

- 当前值；
- 中位数；
- 百分位；
- 样本数。

诊断只说明关联和贡献，不直接宣称因果。

## 9. 数据接入

活动数据必须经过：

`Source → Snapshot → Raw → Staging → Quality → Core → Publish → Semantic`

管理员可以查看：

- 来源；
- 快照；
- 运行；
- 质量；
- 数据版本；
- 发布状态。

## 10. 报告

当前 Integration-Core 提供报告草稿/导出基础。正式报告治理能力如果后续由 P6 发布，应以当时的运行版本和知识基线更新本说明。

报告中的数字只能来自验证过的结构化结果。

## 11. 场景切换

当前主要场景：

- `charging_ops`
- `sales_ops`

场景切换后：

- 指标；
- 维度；
- Schema；
- 数据范围；
- RAG；
- Query Engine

都必须在同一场景上下文内重新解析。

## 12. 权限

系统权限由后端执行，前端显示不是安全边界。

普通用户只能看到授权范围内：

- 指标；
- 场站/区域；
- 结果；
- 知识；
- 报告。

管理员治理能力也不等于自动获得所有经营明细权限。

## 13. 回答可信度检查

用户可以检查：

- run_id；
- dataset version；
- semantic version；
- Query Plan/SQL hash（按角色）；
- Guard 状态；
- Citation；
- 知识版本；
- 数据范围。

没有这些证据的经营数字不应作为正式分析依据。

## 14. 推荐演示流程

1. 打开经营驾驶舱；
2. 查看 charging_ops 活动指标；
3. 使用 ChatBI 查询一个指标；
4. 做环比或场站下钻；
5. 使用 RAG 询问指标口径；
6. 提问“数据 + 口径”的组合问题；
7. 切换 sales_ops；
8. 查看销售收入/订单/客户分析；
9. 演示权限拒绝或 SQL 安全拒绝；
10. 查看 run_id / Citation / Audit 证据。
