## 5. Phase 0 历史问题（已在 Phase 0.1 回答）

以下问题保留为审计轨迹。DEC-01—DEC-10、指标、数据、记忆和时间问题均已回答；当前仅剩 C-01、C-02。

以下问题不能由实现者静默替代：

1. 是否正式批准本项目作为独立 Git 仓库和独立数据域？
2. Alpha 是否只使用规则化模拟数据；是否还存在可合法使用的公共或脱敏替代数据？
3. 是否批准三类 P0 核心用户及其次序？
4. 是否批准 `project_scope_baseline.md` 中的 15 项指标候选？如不批准，具体增删哪些？
5. 可变运营成本是否作为独立指标；复购率的周期/cohort 如何定义；利用率的可用枪口如何定义？
6. 是否批准 P0 完全不提供自由 SQL 或隐藏实验开关？
7. 是否确认报告只生成可审核草稿，自动发送/工单/跨系统执行不属于本项目？
8. 每周可投入时间、Alpha 目标窗口和任何不可变演示日期是什么？
9. 是否批准 P0 只做当前会话结构化状态，长期偏好/历史案例/管理页进入 P1？
10. 组织规则的批准角色具体是谁：管理员、指标负责人，还是两者共同审批？
11. 会话状态、个人偏好和历史案例的具体保留期分别是多少？
12. Alpha 的目标运行环境是什么：Windows 本地 Docker Desktop、Linux 主机，还是两者都要验收？
13. 是否存在组织、租户、区域的真实层级约束，还是 Alpha 只模拟单租户多区域？
14. 谁负责最终 DoR 与 Alpha 验收签署？个人项目是否采用“负责人自签 + 独立复核”模式？
