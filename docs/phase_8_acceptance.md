## 已知限制

- 确定性中文解析只覆盖冻结合同，不是开放域 LLM；
- 报告导出为 Markdown/CSV，不包含原生 DOCX 或服务端 PDF；
- 工作记忆为单进程短期状态，持久会话仅实现获批 P0 字段和 TTL；
- 单机 Compose 不包含生产高可用、备份编排、SSO 或生产多租户；
- 验收全部基于模拟数据和本地容器，未验证真实企业数据或真实收益。

## 回滚

Phase 8 应用变更可回退包含本文件的独立 Git 提交；数据库迁移按目标版本执行 Alembic downgrade。`docker compose down` 保留项目数据卷；只有明确接受删除项目专用模拟数据后才执行 `docker compose down -v`。报告和 analysis_run 是审计证据，普通应用回滚不应删除。
