# 平台定位与边界

## 当前定位

当前产品是“新能源充电运营经营分析的 AI 增强 BI 模块化单体”，不是通用企业级 ChatBI 平台。P0 平台化改造的目标是冻结可复用边界、纠正真实性表达并建立后续解耦路线，不在本阶段伪造已经完成的平台能力。

## 目标定位

目标产品由稳定平台核心和可安装业务场景包组成：

- 平台核心：连接器、数据集版本、语义模型、查询引擎、安全、身份、审计、知识与记忆 Provider 接口。
- 场景包：charging_ops 的实体、字段映射、指标、同义词、问题模板、诊断规则、报告模板和样例数据。
- 产品入口：驾驶舱、受控 ChatBI、诊断、报告草稿和治理界面只消费已发布合同。

## 非目标

- 不提供自由 SQL 编辑器或管理员实验入口。
- 不允许 LLM 直接生成并执行核心 SQL。
- 不拆微服务，不引入多 Agent 自动执行。
- P0 不实现 SQLBot、RAG、长期记忆、多租户或 SSO。
- 不自动发送邮件、创建工单或跨系统执行动作。
- 不把模拟数据、规划功能或静态 UI 文案表述为真实运营事实。

## 成功标准

1. 现有代码被明确归类为 `PLATFORM_CORE`、`CHARGING_OPS`、`MIXED` 或 `DEAD_OR_STALE`。
2. 七类平台合同可供下一阶段按依赖顺序实施。
3. 数据接入失败、生产弱配置和危险 SQL 都是 fail closed。
4. 页面只展示接口返回的事实；未实现功能显示 Disabled、Error 或 Blocked。
5. P0 变更可由独立 Git 提交回滚，并有当前测试证据。
