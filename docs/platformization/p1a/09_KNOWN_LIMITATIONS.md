# P1A 已知限制

## 外部硬阻塞

外部数据库/API 疑似暴露凭据尚未取得以下确认：

- 旧凭据撤销；
- 新凭据轮换；
- 旧凭据不可用；
- 暴露窗口访问日志核查。

因此 `P0_ACCEPTANCE=CONDITIONAL`，不允许进入 P1B 或连接真实外部系统。

## P1A 能力边界

1. 平台版本路由默认关闭，尚未作为默认生产路径；
2. 正式长期 ChatBI 只读 LOGIN 角色未投用，只有脚本和临时运行验证；
3. SQLBot 为 NOT_CONFIGURED；
4. MySQL 未实现批读和增量读；
5. 没有 RAG、长期记忆、多 Agent；
6. 当前单租户运行，虽保留 tenant/workspace/org 字段，但无多租户管理 UI；
7. 只有 `charging_ops` 一个完整场景包；
8. 旧兼容代码尚未删除；
9. 所有数据为模拟数据，不代表企业生产规模、客户使用或经营收益。

## 技术债

- 旧测试夹具对每个参数化用例重建全部 SQLite 表，导致本机运行慢；
- 历史 0006 曾导入 live model，已改为显式 Schema，后续迁移不得再导入可漂移模型；
- 正式只读角色投用前需由外部秘密管理系统配置 LOGIN，并复跑同一负向脚本；
- P1B 前应把平台版本路由开启场景纳入持续集成的 PostgreSQL 套件。
