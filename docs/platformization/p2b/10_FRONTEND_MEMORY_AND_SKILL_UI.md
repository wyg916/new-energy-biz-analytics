# Memory 与 Skill 管理 UI

React UI 新增“记忆与偏好”和“Skill 管理”视图，数据只从正式后端 API 获取。页面不读取
fixture、不随机生成经营结果、接口失败不使用虚构数据兜底。

Memory 视图展示当前偏好、Working State、历史分析、来源、作用域、可信度、版本和过期
时间；受权限控制的查看、更正、确认、拒绝、删除、导出和禁止记忆操作调用真实 API。

Skill 视图展示名称、场景、版本、状态、Owner、输入输出、步骤、校验和 Shadow 结果；
启用、停用和回滚按服务端角色与状态机控制。尚未满足审批、测试或回滚前置条件的按钮被
禁用并显示原因，不提供假按钮或假成功提示。

全局状态区持续显示“模拟数据”、数据时间、来源和 run_id 位置，业务组件不重复堆叠。
前端构建、Vitest、Playwright 和 npm audit 的运行证据记录在验收矩阵。
