# P5 生产数据接入治理

状态：`CONDITIONAL`。本轮未接入真实客户生产数据，平台继续使用 2025-01-01 至 2026-06-30、固定随机种子、业务规则生成并经数据库/API 提供的模拟数据。

## 关闭前审批清单

1. 具名数据 Owner、处理目的、批准范围和到期时间；
2. 表/列级分类，明确 PII、商业敏感、Secret 与禁止模型字段；
3. 最小权限只读账号、允许 schema/view 和网络边界；
4. tenant/workspace 绑定及跨租户负向 Oracle；
5. 样本脱敏、不可逆性验证和再识别风险评估；
6. 保留、删除、Legal Hold、审计和导出政策；
7. Query Guard、Answer Guard 和模型列级裁剪证据；
8. 数据质量、对账和只读验证；
9. 断开连接、CredentialReference 撤回和数据回滚步骤；
10. 审批人、证据哈希、复核要求和过期时间。

任何请求不得选择 tenant/workspace 绕过可信身份；权限过滤必须发生在数据查询和记忆/知识召回前。没有授权列不得提供给模型。回滚是撤回引用、停用数据源并保留审计，不删除生产源数据。
