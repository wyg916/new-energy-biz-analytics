## V2-P0.0：Alpha 封存与基线校准

| 项目 | 内容 |
|---|---|
| 目标 | 复现 Alpha、冻结标签、建立 V2 分支和唯一执行基线 |
| 输入 | Alpha 代码、运行 Compose、冻结合同、V2 v1.0 方案 |
| 输出 | 标签、远程备份、V2 基线、范围/backlog、机器证据、验收报告 |
| 修改范围 | 文档、证据、测试/采集脚本、Git 元数据 |
| 禁止范围 | 所有业务代码、UI、指标、数据接入和后续功能 |
| 测试命令 | README 全量命令；`scripts/verify_alembic_schema_cycle.py`；证据截图 spec |
| 验收标准 | Alpha 可复现；标签/分支正确；证据完整；无敏感信息；工作区干净 |
| 证据 | `docs/v2/evidence/alpha/` |
| 提交格式 | `v2-p0.0: freeze alpha baseline and establish v2 execution control` |
| 回滚 | `git revert <P0.0提交>`；删除远程分支/标签不属于本地回滚步骤 |
| 依赖 | Alpha 验收提交存在且无不可安全保留的用户修改 |
| 工期 | 1 日 |
| 主要风险 | 历史事实漂移、Docker 环境不可用、凭据或敏感文件 |
