# 经营预警 UI 复刻验收

## 目标

在不改变指标口径、查询安全和真实性边界的前提下，将 Figma 节点 `1:2` 的“经营预警”界面落地为产品页面，并确保 1600×900、浏览器 100% 缩放下无需上下滚动即可完整展示。

## 范围

- 六项预警摘要指标；
- 风险、状态、负责人和关键词筛选；
- 预警列表与选中态；
- 业务摘要、指标变化、贡献拆解、影响对象、建议行动和处理记录；
- 模拟数据、数据时间、来源与 `run_id` 证据链；
- 专属一屏布局和 Playwright 验收。

## 非目标

- 不新增或修改指标口径；
- 不自动确认预警、分派负责人或执行行动建议；
- 不将同期指标变化描述为已验证因果；
- 不引入真实企业数据或真实收益数字。

## 数据与安全影响

- 无数据库迁移；
- 只调用现有诊断分解和规则异常只读接口；
- 风险等级、状态和摘要数量由当前结构化诊断结果确定性派生；
- 建议行动仅供人工审核，不触发邮件、工单或跨系统操作。

## 验收标准

1. 六张摘要卡、预警列表和右侧五层详情完整可见；
2. 贡献拆解使用接口返回驱动项并展示对账后的合计影响；
3. 风险筛选可交互，列表选中态可切换；
4. 页面显示模拟数据、数据时间、来源和诊断 `run_id`；
5. 1600×900、100% 缩放下文档无纵向滚动；
6. `.alert-panel` 不发生横向或纵向内部溢出；
7. 页面无浏览器控制台错误；
8. 前端构建、单元测试和专属 Playwright 用例通过。

## 回滚方式

回滚本工作包独立 Git 提交即可；本工作包不涉及数据库回滚。
