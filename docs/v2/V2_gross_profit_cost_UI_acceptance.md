# 毛利与成本 UI 复刻验收

## 目标

在不改变已冻结指标口径、查询安全边界和模拟数据真实性边界的前提下，将 Figma 节点 `1:2` 的“毛利与成本”界面落地为产品页面，并确保 1600×900、浏览器 100% 缩放下无需上下滚动即可完整展示。

## 范围

- 毛利与成本筛选栏、六项核心指标卡；
- 累计悬浮柱与虚线连接的毛利桥接、双环成本结构、带纵轴刻度的度电成本趋势；
- 低毛利率场站表与优化建议；
- 模拟数据、数据时间、来源与 `run_id` 证据链；
- 专属一屏布局与自动化验收。

## 非目标

- 不新增指标口径；
- 不开放自由 SQL；
- 不引入真实企业数据；
- 不自动执行优化建议、发送邮件或创建工单；
- 不宣称设备变化或建议与经营结果存在已验证因果关系。

## 数据库与安全影响

- 无数据库迁移；
- 仅调用现有只读指标、趋势和诊断接口；
- 权限过滤、已发布指标校验和诊断对账链路保持不变；
- 页面只展示模拟数据及可审核建议，不执行外部动作。

## 验收标准

1. 六项核心指标、三个分析模块、低毛利场站表和四条优化建议可见；
2. 毛利桥接柱按接口返回贡献项逐项累计，起止毛利完成对账；成本结构完整显示占比、金额和图例；
3. 页面显示“模拟数据”、数据时间、来源和诊断 `run_id`；
4. 1600×900、100% 缩放下文档无纵向滚动；
5. `.margin-panel` 不发生横向或纵向内部溢出；
6. 页面无浏览器控制台错误；
7. 前端构建、单元测试和专属 Playwright 用例通过。

## 回滚方式

回滚本工作包独立 Git 提交即可；本工作包不涉及数据库回滚。
